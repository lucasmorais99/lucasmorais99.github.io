Um jeito simples de explorar a base

Este protótipo não requer um processo de build.

01

Pergunte naturalmente

Escreva a dúvida como escreveria para um colega. Comece por perguntas com resposta conhecida para validar o sistema.

02

Peça a fonte

Solicite o nome do arquivo e, quando disponível, a página, seção ou aba que sustenta a resposta.

03

Valide os números

Buscas em planilhas ajudam a localizar dados, mas somas, médias e comparações extensas devem ser conferidas.

Protótipo de demonstração — não envie dados confidenciais.
